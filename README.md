# Detecting Fraudulent Job Postings Using Text Analytics

INSY 669/670 group project: Julia Al Rifai, Katerina Avvakumova, Mia Ghrayeb, Daniel Puente Cavazos, Alex Zhao

Job platforms receive too many postings for moderators to check each one. This project builds a **fraud-risk score**
from posting text and metadata, so moderators can review the riskiest postings first.

## Research questions
1. Do fraud signals come from the **text**, the **metadata**, or both?
2. Do more complex models beat a tuned TF-IDF + logistic regression baseline?
3. What language distinguishes fraudulent postings?
4. Do distinct fraud *types* emerge without labels (NMF topic modeling)?
5. How much fraud is caught if moderators review only the top X% riskiest postings?

## Setup
1. Download the **Real or Fake Job Posting Prediction** dataset (EMSCAD) from Kaggle
   and save `fake_job_postings.csv` in `data/`.
2. `pip install -r requirements.txt`
3. Open the notebook and run all cells (about 15–25 min on a laptop; the random forest grid search is the slowest part).

## Data
EMSCAD (University of the Aegean): 17,880 job postings, 866 (4.8%) labelled fraudulent.
Text fields: title, company profile, description, requirements, benefits.
Metadata: telecommuting, company logo, screening questions, salary, employment type, experience, education, industry,
function, location.
